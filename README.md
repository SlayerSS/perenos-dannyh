# Перенос данных

Программа **IT Сервис, Ноябрьск** для переезда офисного компьютера на чистую Windows.
Копируются только файлы и настройки пользователя. Сами программы на новом компьютере ставятся отдельно и подхватывают свои данные.

## Скачать

В [релизе 1.0.0](https://github.com/SlayerSS/perenos-dannyh/releases/tag/v1.0.0) два файла:

| Файл | Когда ставить |
| --- | --- |
| `PerenosDannyh-so-vstroennym-NET.exe` | Обычный случай. .NET ставить не нужно. |
| `PerenosDannyh-bez-NET.exe` | Если на компьютере уже есть [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0). Файл меньше. |

Нужна 64-разрядная Windows.

## Как пользоваться

1. **Живая система → папка.** Сохранить данные этого компьютера на диск или флешку.
2. **Папка → живая система.** Вернуть сохранённую копию на новый компьютер.
3. **Диск → живая система.** Взять профиль со старого диска. Если Windows не пускает в чужую папку, нажмите «Дать доступ» или сразу «Найти данные»: закрытые файлы будут пропущены.

Диск в первом режиме — только место, куда сохранить копию. Служебный раздел «Зарезервировано системой» для копии не подходит.

## Что переносится

- Рабочий стол, документы, загрузки, изображения, избранное. Музыка и видео по умолчанию выключены.
- Chrome, Edge, Яндекс Браузер, Opera, Brave и Firefox: закладки, пароли, история, последние вкладки, куки и настройки расширений. Кэш и служебные модели не копируются.
- Outlook: настройки, подписи и отдельно отмеченные архивы PST.
- 1С: список баз `ibases.v8i`, настройки пользователя и отдельно отмеченные файловые базы.
- Office: шаблоны, словарь, автозагрузка Word и Excel, надстройки, недавние документы, личные настройки.
- Сетевые диски пользователя.
- Thunderbird, The Bat! и, по отдельному подтверждению, ключи CryptoPro.

Игры, обои, кэш браузеров и папки программ не копируются.

## Что ставится заново

Windows, Office, 1С, КриптоПро, банковский клиент, драйверы принтеров. Серверная база 1С и почта Exchange остаются на сервере: с диска забирается только подключение и, для Outlook, файл PST, если он есть.

## Сборка

```powershell
dotnet publish DataMigrator -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
dotnet publish DataMigrator -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```
